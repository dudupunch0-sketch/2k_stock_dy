# 두루미 주식 — 요구사항과 인터뷰 기록

상태: 요구사항 수집 중. 구현 승인·배포·예약 활성화가 완료된 문서는 아니다.
작성일: 2026-10-04

## 사용자가 확정한 조건

- 국내·미국 주식을 모두 지원한다.
- 투자 관점은 약 2년이다.
- 우선순위: 요청한 기업의 상세 분석 → 관심·보유 종목의 변화 추적 → 보유 투자 근거 점검.
- 신규 종목 발굴·스크리닝은 제외한다.
- 보유 약 3종목, 관심 약 10종목을 관리한다. 실제 명단은 아직 미제공이다.
- 개별 상세 분석은 사용자가 요청할 때 실행한다.
- 자동 보고는 금요일 오전 10시를 기준으로 한다. 한국시간(Asia/Seoul)을 설계 기본값으로 제안한다.
- 지난 일주일의 중요 공시·실적·뉴스를 주간 보고에 포함한다. 이전에 논의한 일별 감시·별도 이벤트 알림 요구는 철회되었다.
- ChatGPT Plus의 Work 클라우드에서 사용하며 GitHub 저장소와 연동한다.
- 반복 실행 모델은 사용자가 말한 “GPT Luna medium”이다. 구체적인 모델 버전은 아직 명시되지 않았다.
- 결과물은 요약·상세 분석·필요한 차트를 포함하는 재사용 가능한 인터랙티브 HTML이다.
- 보수·기준·낙관 시나리오와 가치평가 범위를 제공한다. 최종 투자 판단은 사용자가 한다.
- 이 public 저장소를 공개 투자 일기 용도로 사용한다.
- 첫 검증 종목은 에이피알이다. 보유 여부는 확인되지 않았으며 미국 검증 종목은 아직 지정되지 않았다.
- 사용자는 1회 실행의 예상 토큰량과 Plus 5시간 한도 대비 소모율을 알고 싶어 한다.

## 기존 분석 요청에서 유지할 범위

1. 기업·산업 개요, 3줄 요약, 사업모델·주력제품·수익구조, 5년 매출·단가·원재료·이익률, 최근 제품별 매출 비중.
2. 재무제표와 전망: 매출·영업이익·순이익·EPS·PER·PBR·ROE, 증권사 예상 실적과 보고서 출처.
3. 투자포인트·리스크: 업황·기업 성장·실적 대비 가치·주가 위치, 시장점유율·경쟁우위·사업 확장, 일회성 비용·가격 인하·정책·환율·유가.
4. 장기 산업 성장·시장 규모, Google Trends 관심도, 외국인·기관 투자 동향.
5. 경제적 해자: 반복구매·사용자 및 수요 증가·고객 유지·대체재·경쟁우위.
6. 경쟁사 2개 비교: 시가총액·매출·영업이익·이익률·순이익·EPS·PER·PBR·ROE, 최근 연간 실적 및 전망.
7. 영업 레버리지·비용 전망·잠재시장·점유율.
8. 최근 IR 핵심과 중요한 뉴스 3개, 실질적인 가치평가·시나리오를 보완한다.
9. 국내 기업은 한경컨센서스의 최근 보고서 최대 3개와 각 3줄 요약. 미국 자료의 대체 출처는 추가 선정한다.

## 제안한 설계 원칙 — 상세 구현 전 확정 필요

- 원문 자료 수집 → 수치 정규화·검산 → AI의 구조화된 분석 → 공통 HTML 생성기.
- 프로그램이 표·차트·산식·화면을 재사용한다. AI가 매번 화면 코드를 작성하지 않는다.
- 기존 분석과 자료별 변경 기록을 저장해, 주간 보고는 변화 중심으로 생성한다. 중요한 변화가 있으면 관련 분석을 충분히 갱신한다.
- 고정된 2022~2026년 대신 분석 기준일과 기업 회계연도에 따라 기간을 정한다.
- 확정 실적, 잠정 실적, 회사 가이던스, 개별 증권사 전망, 여러 기관의 컨센서스, AI 시나리오를 구분한다.
- 수치에는 출처·공시/발표일·수집일·기간·통화·단위·연결/별도 기준을 보관한다. 비교 조건과 주가 기준일을 일치시킨다.
- 현금흐름·부채·일회성 손익을 포함한다. 정정 공시는 이전 기록과 변경 이유를 남긴다.
- 단가·시장점유율 등 비공개 수치를 만들어 채우지 않는다. 부족한 자료와 확보한 보고서 개수를 그대로 밝힌다.
- 시나리오에는 매출 성장률·이익률·주식수/희석·평가 배수 등 가정과 근거, 반증 조건을 제시한다.
- 자동 생성한 AI 분석과 사용자가 직접 작성한 투자 일기를 구분하고 과거 시점의 판단을 보존한다.
- 공개 저장소에는 재사용 코드, 공개 가능한 데이터와 자체 분석·출처 링크를 저장한다. 인증키는 별도의 비밀 저장 기능을 사용한다.
- Work 예약 실행이 사용할 코드·설정·이전 기록을 매번 복원할 수 있게 한다. 이 세션에서 Work 클라우드 실행을 검증한 것은 아니다.

## 사용량 평가

공식 OpenAI 설명에 따르면 Work와 Codex는 사용 한도를 공유하며, 모델·맥락·추론·도구·검색·캐시가 소모량에 영향을 준다. API 토큰 가격을 구독 포함 사용량으로 환산하면 안 된다. 공개 문서에 Plus 5시간 한도 전체의 고정 토큰 수나 보고서당 소모율은 없다.

따라서 구현 전 1회 소모율을 측정치처럼 기재하지 않는다. 가공한 분석 입력·최종 출력의 토큰 예산과 실제 실행 전체 사용량을 구분한다.

시범 실행 계획:
- 동일한 Luna 버전·medium·Standard 설정을 기록한다.
- 다른 작업이 겹치지 않는 동일한 한도 구간에서 실행 전후 계정 사용률을 기록한다.
- 실행 사이 한도가 리셋되면 해당 비교는 폐기한다.
- 전후 사용률 차이를 전체 한도 대비 퍼센트포인트로 기록한다. 정수 단위 표시와 반영 지연을 고려한다.
- 확인 가능한 입력·출력·캐시·추론 토큰만 실제 수치로 기록한다. 노출되지 않는 항목은 미확인으로 남긴다.
- 신규 상세 분석, 변화가 적은 주간 보고, 실적 발표가 많은 주간 보고를 별도로 측정한다.

## 남은 결정

- 무료 OpenDART 인증키 보유·발급 가능 여부와 Work에서의 안전한 공급 방식.
- 별도 유료 데이터 허용 범위. 우선 추가 유료 서비스 없이 시작하는 안을 제안한다.
- 에이피알의 보유/관심/검증용 구분과 사용자가 주목하는 투자 근거.
- 실제 관심·보유 명단, 가격·컨센서스의 확보 가능한 출처, 미국 검증 종목.
- 보고서 공개 화면의 호스팅 여부와 게시 절차.
- Work 클라우드에서의 코드 실행·기록 저장·HTML 열람·예약 실행 검증.
